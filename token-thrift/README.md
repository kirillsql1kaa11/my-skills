# token-thrift

Меньше токенов без потери качества: никаких дублей, простыней и лишних кругов.

**Инструмент:** opencode
**Триггер:** автоматически, в каждой сессии

## Что делает

- Запрещает перепечатывать в ответ код, диффы и вывод команд — вместо этого ссылки
- Цитирует минимально: значимая строка с контекстом, остальное адресом
- Просит обрезать вывод команд: фильтры, `--quiet`, первые N строк
- Батчит независимые вызовы в один блок — меньше кругов, меньше пересылки контекста
- Запрещает перечитывать неизменное; после правок проверка делом, а не чтением
- Держит ответ коротким без вступлений и объяснения очевидного
- Не плодит файлы и планы «на всякий случай», заканчивает, когда цель достигнута

## Границы

Экономия неприкосновенно уступает: проверке результата, чтению нужного кода, разведке незнакомого проекта, рискам и важным вопросам. Сомнение «прочитать или сэкономить» решается в пользу чтения.

## Установка

```powershell
Copy-Item -Recurse token-thrift "$env:USERPROFILE\.config\opencode\skills\"
```
