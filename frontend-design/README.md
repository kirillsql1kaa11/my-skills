# frontend-design

Подход к визуальному дизайну: намеренные, авторские решения вместо шаблонных дефолтов, которые читаются как «сгенерировано по умолчанию».

**Инструмент:** Google Antigravity
**Триггер:** проектирование нового интерфейса или переработка существующего

## Что делает

- Приземляет дизайн в предметную область брифа: индустрия, материалы, язык аудитории — источник отличительных визуальных решений
- Задаёт принципы: герой открывает самую характерную вещь продукта; типографика несёт характер; структура кодирует информацию, а не декорирует
- Перечисляет типовые «следы» сгенерированных страниц, которых следует избегать как дефолтов: кремовый фон с terracotta-акцентом, все капсом, нумерация без последовательности, набор одинаковых скруглённых карточек, ALL-CAPS eyebrows
- Работает в два прохода: дизайн-план (цвет, типографика, раскладка, принципы) → проверка плана против брифа → сборка → самокритика
- Дисциплина сдержанности: смелость тратится в одном месте, вокруг всё тихо и аккуратно
- Отдельный блок про текст в интерфейсе: писать от лица пользователя, активный голос, согласованность словаря, понятные ошибки и пустые состояния
- Напоминает про базовый уровень качества: адаптив до мобильных, видимый клавиатурный фокус, `prefers-reduced-motion`, доступные палитры
