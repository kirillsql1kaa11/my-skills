# dom-mutation-watcher

Стандарты работы с `MutationObserver` в браузерных расширениях и веб-клиентах: батчинг мутаций, фильтрация, защита от бесконечных циклов, очистка ресурсов.

**Инструмент:** Google Antigravity
**Триггер:** модификация динамических интерфейсов, разработка клиентских расширений

## Что делает

- Запрещает тяжёлые вычисления и `querySelectorAll` синхронно в колбэке мутаций
- Требует сужать область наблюдения и ограничивать параметры (`attributeFilter`, `subtree` только при необходимости)
- Предотвращает бесконечные циклы: маркировка изменённых узлов через `data-*` или временное отключение наблюдателя
- Требует освобождать ресурсы через `disconnect()` при выгрузке страницы или смене маршрута
- Даёт готовый класс `DomBatchWatcher` на TypeScript: пакетная обработка добавленных узлов через `requestAnimationFrame`
- Показывает паттерн `waitForElement` с промисификацией — без `setInterval`
- Завершается чек-листом: нет периодического опроса DOM, наблюдение останавливается явно, в коде нет комментариев

## Установка

```powershell
Copy-Item -Recurse dom-mutation-watcher "$env:USERPROFILE\.gemini\config\skills\"
```
