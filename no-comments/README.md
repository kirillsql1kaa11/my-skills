# no-comments

Правило нулевых комментариев: любой новый или изменяемый код пишется без комментариев — включая docstring и JSDoc. Пояснения «зачем» уходят в ответ пользователю, а не в код.

**Инструмент:** opencode
**Триггер:** автоматически, для каждого фрагмента кода

## Что делает

- Запрещает комментарии в любом виде: `//`, `/* */`, `#`, `--`, `<!-- -->`, docstring, JSDoc
- Требует самодокументируемый код: выразительные имена, короткие функции с одной ответственностью, явные типы
- Выносит пояснения в ответ после кода
- Не трогает чужие комментарии в существующем проекте и не размножает новые в правимом фрагменте
- Разрешает только объективно обязательные исключения: лицензионные шапки, shebang, директивы линтера, внешние спецификации
- Перед сдачей проверяет diff: не появилось ли новых комментариев

## Установка

```powershell
Copy-Item -Recurse no-comments "$env:USERPROFILE\.config\opencode\skills\"
```
