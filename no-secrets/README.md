# no-secrets

Секреты, токены и персональные данные не попадают в код, коммиты и логи.

**Инструмент:** opencode
**Триггер:** автоматически, перед коммитами и при работе с конфигами, логами, примерами

## Что делает

- Запрещает реальные ключи и пароли в исходниках, тестах и примерах — только плейсхолдеры
- Указывает правильные источники: переменные окружения, `.env` в `.gitignore`, менеджер секретов
- Требует просмотра индекса перед коммитом: ключи, токены, длинные base64/hex, `password=`
- Проверяет `.gitignore` до первого `git add -A`
- Убирает секреты и персональные данные из логов, ошибок и вывода — с маскированием
- Объясняет порядок при инциденте: ротация ключа → чистка истории → force push только с согласия
- Не печатает содержимое `.env` и хранилищ секретов даже в ответах

## Установка

```powershell
Copy-Item -Recurse no-secrets "$env:USERPROFILE\.config\opencode\skills\"
```
