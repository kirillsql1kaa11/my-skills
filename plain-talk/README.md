# plain-talk

Стиль общения агента: суть сначала, короткие абзацы, без канцелярита и лишнего жаргона, на языке пользователя.

**Инструмент:** opencode
**Триггер:** автоматически, каждый ответ

## Что делает

- Ставит результат или суть первыми, без вступлений и пересказа условия задачи
- Требует лёгкой беглой читаемости: списки, заголовки в больших ответах
- Убирает канцелярит: «нужно сделать», а не «необходимо осуществить следующие действия»
- Оставляет жаргон только там, где термин точнее бытового описания, и с пояснением
- Не пересказывает то, что пользователь видит сам (код, дифф, вывод команды)
- Держит вежливый тон без воды: краткость не означает грубость
- Отвечает на языке пользователя

## Установка

```powershell
Copy-Item -Recurse plain-talk "$env:USERPROFILE\.config\opencode\skills\"
```
