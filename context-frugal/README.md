# context-frugal

Точечный поиск по коду вместо чтения всего репозитория: сначала найти, потом прочитать нужное.

**Инструмент:** opencode
**Триггер:** автоматически, при исследовании кода и поиске по проекту

## Что делает

- Ставит поиск перед чтением: файлы открываются по найденным адресам, а не «на посмотреть»
- Ограничивает чтение: `offset`/`limit`, от нужного символа, 2–3 перехода по вызовам
- Исключает шум в самом поиске: `node_modules`, `.git`, `dist`, `build`, `vendor`
- Учит искать по уникальным строкам и расширять шаблон только при нуле результатов
- Собирает независимые поиски в один заход
- Запрещает перечитывать уже прочитанное
- Требует отвечать адресом `путь:строка` и минимальной цитатой
- Останавливает на решающем доказательстве, а не на полном обходе
- Не позволяет экономить на точности: непрочитанное — прочитать, а не додумать

## Установка

```powershell
Copy-Item -Recurse context-frugal "$env:USERPROFILE\.config\opencode\skills\"
```
