# Правило: Windows без сюрпризов

Окружение — Windows. При выполнении команд и правке файлов соблюдать:

1. **Shell — PowerShell.** Синтаксис только его: `$env:VAR`, `|`, `Get-ChildItem`, `Select-Object`. bash-команды (`which`, `sed`, `wc`) и цепочки `&&`/`||` в Windows PowerShell 5.1 не работают — заменять аналогами (`Get-Command`, `Select-String`, `Measure-Object`).
2. **Шимы и лончеры.** `npm`, `npx`, `yarn` — через `.cmd`-версии (`npm.cmd`), если `.ps1` блокируется политикой выполнения. `python3` в PATH обычно нет — использовать `py -3` или `python`.
3. **Пути.** Пробелы — в кавычках, сборка через `Join-Path`. Разделители `\` и `/` PowerShell понимает оба. Зарезервированные имена (`CON`, `NUL`, `COM1`, `aux`) не создавать. Файловая система регистронезависима: два файла, различающиеся только регистром, не сосуществуют. Путь длиннее 260 символов может не работать без включённой поддержки длинных путей.
4. **Кодировка — UTF-8, явно.** `-Encoding utf8` в Windows PowerShell 5.1 добавляет BOM; в PowerShell 7 `utf8` — уже без BOM. При кракозябрах в выводе: `chcp 65001`, `[Console]::OutputEncoding`, `[Console]::InputEncoding`, `$OutputEncoding`.
5. **Переводы строк не трогать.** Существующие CRLF/LF сохранять как есть; массовая нормализация — только по явной просьбе. Для новых файлов — как в проекте (`.gitattributes`).
6. **Процессы и порты.** Занят порт — `Get-NetTCPConnection -LocalPort <N>`, владелец — `Get-Process -Id`, завершение — `Stop-Process`. Чужие процессы без разбора не завершать.
7. **Удаление и перемещение — по точному пути.** Перед `Remove-Item -Recurse -Force` проверить путь (`Resolve-Path`), убедиться, что переменная не пустая и что это тот самый каталог. Никаких удалений по «похоже, оно».
