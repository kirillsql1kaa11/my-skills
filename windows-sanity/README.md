# windows-sanity

Работа в Windows без сюрпризов: правильный шелл, безопасные пути, явная кодировка UTF-8 и сохранные переводы строк.

**Инструмент:** opencode
**Триггер:** автоматически, при командах и работе с файлами в Windows

## Что делает

- Заменяет bash-синтаксис на PowerShell-эквиваленты (`which` → `Get-Command`, `wc` → `Measure-Object`, `$env:VAR`)
- Помнит про `.cmd`-шимы (`npm.cmd`) и `py -3` вместо недоступного `python3`
- Защищает от ловушек путей: пробелы, зарезервированные имена, регистронезависимость, длинные пути
- Требует явную кодировку и учитывает BOM в PowerShell 5.1
- Запрещает самовольную нормализацию CRLF/LF
- Проверяет владельца порта и процесса перед завершением
- Держит `Remove-Item -Recurse -Force` на точных проверенных путях

## Установка

```powershell
Copy-Item -Recurse windows-sanity "$env:USERPROFILE\.config\opencode\skills\"
```
