# Адаптивность по умолчанию

При вёрстке любого UI — страницы, компонента, формы, таблицы — соблюдать без напоминаний:

1. **Mobile-first.** Базовые стили для узкого экрана, усиления через `min-width`.
2. **Проверочные точки:** 375, 768, 1024, 1440 px (и 320 для самых мелких). Мысленно прогнать макет на каждой.
3. **Никакого горизонтального скролла страницы.** Его причине — фикс-ширины, длинные слова, широкие таблицы — устранять, а не прятать.
4. **Резиновые размеры.** Контейнеры и колонки через `%`, `max-width`, `fr`, `auto-fit`; типографика через `clamp()`; запредельные px-ширины запрещены.
5. **Медиа:** `max-width: 100%`, `height: auto`, `aspect-ratio` для резерва места, ленивые загрузка и `srcset` там, где уместно.
6. **Необрезаемый текст:** длинные слова и URL — `overflow-wrap: anywhere`; чипы/бейджи/навигация переносятся на новую строку, а не опускаются в никуда; заголовкам — осмысленный перенос.
7. **Столы и код:** широкие таблицы — обёртка с `overflow-x: auto` и видимым хинтом прокрутки; блоки-листы не выпадают из макета.
8. **Тач-условия:** зоны клика от 44×44px без слипания; поведение, живущее только на hover, дублируется по тапу/фокусу.
9. **Мобильная навигация и safe-area:** на малых экранах — таббар/бургер-меню, отступы `env(safe-area-inset-*)` учтены, запрет зума не ставится.
10. **Перед сдачей** перечислить в уме 375/768/1024/1440 для ключевых блоков: hero, форма, таблица, карточки, футер. Сомнительный блок — проверить правкой CSS или признать ограничение вслух.

Совместно с скиллом ui-ux-pro-max: при сомнении в паттерне — запрос `"responsive layout" --stack <стек>`.
