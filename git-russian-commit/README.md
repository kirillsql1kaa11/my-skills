# git-russian-commit

Регламент создания коммитов в Git: сообщения строго на русском языке, без эмодзи, с предварительным аудитом staged-изменений.

**Инструмент:** Google Antigravity
**Триггер:** подготовка, создание или переформулирование коммитов

## Что делает

- Устанавливает главные правила: русский язык, полный запрет эмодзи и декоративных символов, осмысленность, атомарность
- Запрещает общие формулировки: «правки», «фикс», «обновление», «wip», «test»
- Задаёт порядок выполнения: `git status` → `git diff` → точечная индексация `git add` → проверка `git diff --staged` → коммит
- Требует убедиться, что в изменения не попали временные файлы, артефакты сборки и секреты
- Формат сообщения: глагол в неопределённой форме с заглавной буквы («Добавить…», «Исправить…», «Оптимизировать…»)
- Поддерживает многострочные сообщения: заголовок до 72 символов и тело через пустую строку
- Приводит примеры недопустимых и корректных сообщений

## Установка

```powershell
Copy-Item -Recurse git-russian-commit "$env:USERPROFILE\.gemini\config\skills\"
```
