# cleanup-temp

Автоуборка за собой: агент в конце задачи сам удаляет временные файлы, скрипты и каталоги, которые создал по ходу дела, и докладывает одной строкой.

**Инструмент:** opencode
**Триггер:** автоматически, завершение любой задачи с временными артефактами

## Что делает

- Составляет перечень созданного: пути, назначение, используется ли чем-то оставшимся
- Проверяет, что объект действительно временный и не является результатом задачи
- Удаляет в один проход; свои артефакты по умолчанию кладёт во временный каталог среды и чистит именно его
- При сомнении (большой объём, неясное происхождение) переносит в `_trash_<дата>` вместо удаления
- Никогда не трогает файлы и данные пользователя, существовавшие до начала задачи

## Установка

Скопируйте каталог `cleanup-temp` в папку скиллов opencode:

```powershell
Copy-Item -Recurse cleanup-temp "$env:USERPROFILE\.config\opencode\skills\"
```
