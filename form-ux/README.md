# form-ux

Формы без боли: понятные ошибки, ввод не теряется, доступность по умолчанию.

**Инструмент:** opencode
**Триггер:** автоматически, при создании и правке форм, полей и валидации

## Что делает

- Требует настоящие `<label>` и честные плейсхолдеры-примеры
- Валидация на `blur` и отправке — без помех вводу и без вычищения символов
- Человеческие тексты ошибок у полей, сводка и фокус на первом неверном
- Защищает ввод: ошибка не сбрасывает форму, черновик переживает перезагрузку
- Разводит состояния кнопки и исключает двойную отправку
- Доступность: `aria-invalid`, `aria-describedby`, `role="alert"`, фокус, Enter/Esc
- Правильные `type`/`inputmode`/`autocomplete` и разрешённая вставка из буфера
- Парольные правила по-человечески: длина важнее состава, менеджеры паролей разрешены
- Ошибки API раскладываются по полям, данные остаются на месте

## Установка

```powershell
Copy-Item -Recurse form-ux "$env:USERPROFILE\.config\opencode\skills\"
```
