# code-review-agent

Глубокое структурированное код-ревью изменений: логика, граничные случаи, безопасность, производительность, архитектура.

**Инструмент:** Google Antigravity
**Триггер:** запросы на ревью кода, аудит пулл-реквестов, проверка диффа перед коммитом

## Что делает

- Фокусируется на логике, надёжности и безопасности, а не на вкусовых предпочтениях форматирования
- Оценивает влияние изменений на всю систему, а не только изолированный diff
- Проверяет по чек-листу направлений:
  - логическая корректность: граничные условия, таймауты, гонки, рекурсия
  - безопасность: валидация ввода, инъекции, утечка секретов в репозиторий, стойкость криптографии
  - производительность: N+1, освобождение дескрипторов, аллокации в горячих циклах, блокирующий I/O
  - архитектура: единственная ответственность, утечка деталей реализации, самодокументируемые имена, мёртвые импорты
- Оформляет каждое замечание с уровнем критичности: Критично (Blocker), Важно (Major), Предложение (Minor)
- Даёт готовое решение вместе с объяснением проблемы
- Формирует отчёт по фиксированной структуре с вердиктом: готово к слиянию, требуются правки, блокирующие проблемы

## Установка

```powershell
Copy-Item -Recurse code-review-agent "$env:USERPROFILE\.gemini\config\skills\"
```
