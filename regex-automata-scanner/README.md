# regex-automata-scanner

Построение высокопроизводительных движков многошаблонного поиска на Rust: сотни сигнатур за один проход без последовательных проверок в цикле.

**Инструмент:** Google Antigravity
**Триггер:** разработка сканеров секретов, парсеров логов, оптимизация строкового поиска

## Что делает

- Запрещает последовательный `Regex::is_match` по списку выражений в цикле
- Требует `regex_automata::meta::Regex` или составной DFA для сопоставления всех шаблонов сразу
- Показывает сканирование байтовых срезов `&[u8]` без обязательной валидации UTF-8
- Требует отключать capturing groups в горячем сканировании и извлекать координаты только после совпадения
- Даёт готовый каркас `SecretScanner` с `build_many` и `find_iter`
- Добавляет префильтр на Aho-Corasick для обязательных литералов (`ghp_`, `AKIA`, `eyJh`)
- Распараллеливает обход файлов через Rayon при переиспользовании скомпилированного движка
- Завершается чек-листом и требованием бенчмарков пропускной способности через Criterion

## Установка

```powershell
Copy-Item -Recurse regex-automata-scanner "$env:USERPROFILE\.gemini\config\skills\"
```
