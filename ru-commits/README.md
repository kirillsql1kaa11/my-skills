# ru-commits

Сообщения коммитов и описания релизов — на русском языке, по conventional commits, из диффа, без шаблонов и эмодзи.

**Инструмент:** opencode
**Триггер:** автоматически перед каждым коммитом и публикацией релиза

## Что делает

- Запрещает пустые шаблоны: «update», «fix», «изменения», «правки», «wip»
- Требует сначала посмотреть `git status` и `git diff` — сообщение пишется из реальных изменений, а не по памяти
- Разбивает независимые изменения на отдельные коммиты: один коммит — одна тема
- Формат — conventional commits с русским описанием: `feat: добавить валидацию email в форме регистрации`
- Тема до 72 символов, глагол в неопределённой форме, без точки в конце
- Тело — когда суть не передать одной строкой: что изменено, зачем, breaking changes
- Запрещает эмодзи и пиктограммы в коммитах, заголовках и описаниях релизов
- Критерий осмысленности: человек, не открывавший дифф, понимает, что изменилось и зачем

## Установка

```powershell
Copy-Item -Recurse ru-commits "$env:USERPROFILE\.config\opencode\skills\"
```
