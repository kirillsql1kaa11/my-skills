# project-brief

Разведка незнакомого проекта при первой работе в каталоге: стек, структура, команды запуска и тестов, конвенции — без просьбы пользователя. Находки дописываются в `AGENTS.md`, чтобы будущие сессии не расследовали всё заново.

**Инструмент:** opencode
**Триггер:** автоматически при первом обращении к незнакомому проекту

## Что делает

- Ищет корень проекта по маркерам: `package.json`, `pyproject.toml`, `Cargo.toml`, `go.mod`, `*.sln`, `pom.xml`, `composer.json`, `build.gradle`, `.git`
- Читает верхний уровень: `README*`, `AGENTS.md`, `CLAUDE.md`, `Makefile`, `docker-compose*`, CI-конфиги
- Определяет стек по манифестам и lock-файлам
- Собирает команды: запуск, сборка, тесты, линт
- Замечает нестандартное: структуру каталогов, нейминг, где тесты, монорепо
- Выдаёт сводку на 5–10 строк и фиксирует её в `AGENTS.md`
- Не копает глубже необходимого: разведка — карта для задачи, а не чтение всего репозитория

## Установка

```powershell
Copy-Item -Recurse project-brief "$env:USERPROFILE\.config\opencode\skills\"
```
