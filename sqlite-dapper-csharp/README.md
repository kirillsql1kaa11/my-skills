# sqlite-dapper-csharp

Стандарты работы с локальной SQLite через микро-ORM Dapper в C# / .NET: пул соединений, прагмы производительности, транзакции, тесты.

**Инструмент:** Google Antigravity
**Триггер:** проектирование репозиториев данных и локальных баз на C#

## Что делает

- Требует параметризованные запросы во всём коде — исключение SQL-инъекций
- Включает WAL и `synchronous = NORMAL` для скорости записи
- Требует выполнять пакетные вставки исключительно внутри `IDbTransaction`
- Заставляет оборачивать соединения в `using` / `await using`
- Даёт фабрику соединений `IDbConnectionFactory` с применением прагм при открытии
- Показывает шаблон репозитория: инициализация схемы, запрос по SKU с `QuerySingleOrDefaultAsync`, пакетная вставка в транзакции
- Описывает тестирование на базе в памяти `Data Source=:memory:` с удержанием соединения и тестовой фабрикой
- Завершается чек-листом: нет конкатенации SQL, нет комментариев, пакеты в транзакциях, проверен параллельный доступ

## Установка

```powershell
Copy-Item -Recurse sqlite-dapper-csharp "$env:USERPROFILE\.gemini\config\skills\"
```
