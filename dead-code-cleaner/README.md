# dead-code-cleaner

Поиск и безопасное удаление мёртвого кода: неиспользуемых функций, переменных, импортов и зависимостей — с валидацией тестами на каждом шаге.

**Инструмент:** Google Antigravity
**Триггер:** чистка мёртвого кода, аудит неиспользуемых сущностей, оптимизация перед коммитом или ревью

## Что делает

- Требует запустить тесты до начала изменений и после каждого шага удаления
- Даёт процедуры под каждый стек:
  - Rust: `cargo clippy` с `-W dead_code`, `cargo udeps`, проверка публичного API в `src/lib.rs`
  - C# / .NET: `dotnet format --diagnostics IDE0005`, коды `CS0168`, `CS0219`, `CS0414`, `IDE0051`, `IDE0052`
  - JavaScript / TypeScript: `knip`, `eslint --fix` для неиспользуемых переменных, чистка `package.json`
  - Python: `ruff check --select F401,F841 --fix`, глубокий поиск через `vulture`, `pytest` после
- Запрещает оставлять комментарии и заглушки вместо удалённого кода
- Фиксирует изменения отдельным осмысленным коммитом на русском языке
- Завершается контрольным списком: тесты зелёные, временных файлов анализаторов нет, `git diff` — только удаление

## Установка

```powershell
Copy-Item -Recurse dead-code-cleaner "$env:USERPROFILE\.gemini\config\skills\"
```
