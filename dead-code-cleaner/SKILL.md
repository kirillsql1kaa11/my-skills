# Регламент очистки неиспользуемого кода (dead-code-cleaner)

Данный навык определяет порядок обнаружения и безопасного удаления неиспользуемого кода, методов, переменных, импортов и зависимостей.

## Основные принципы

1. Запускать автоматические тесты до начала любых изменений.
2. Использовать специализированные статические анализаторы для каждого стека.
3. Удалять код без оставления комментариев и заглушек.
4. Проверять компиляцию и повторно запускать тесты после каждого шага удаления.
5. Фиксировать изменения отдельным осмысленным коммитом на русском языке.

---

## Диагностика и очистка по языкам

### 1. Rust

Шаг 1. Проверка встроенным компилятором и линтером:
```powershell
cargo check
cargo clippy --all-targets -- -W dead_code -W unused_imports -W unused_variables
```

Шаг 2. Поиск неиспользуемых внешних зависимостей (crates):
```powershell
cargo udeps --all-targets
```

Шаг 3. Удаление обнаруженных элементов:
- Удалить функции, структуры и поля, на которые компилятор выдал предупреждения `dead_code`.
- Удалить неиспользуемые импорты (`unused_imports`).
- Если функция предназначена для публичного API библиотеки, проверить файл `src/lib.rs` перед удалением.

Шаг 4. Валидация:
```powershell
cargo test
```

---

### 2. C# / .NET

Шаг 1. Запуск сборки с фиксацией диагностик неиспользуемого кода:
```powershell
dotnet build /warnaserror:false
```

Шаг 2. Автоматическое удаление неиспользуемых директив `using`:
```powershell
dotnet format --diagnostics IDE0005
```

Шаг 3. Анализ неиспользуемых приватных членов:
- Коды предупреждений компилятора: `CS0168`, `CS0219`, `CS0414`, `IDE0051`, `IDE0052`.
- Удалить найденные приватные поля, локальные переменные и вспомогательные методы.

Шаг 4. Валидация:
```powershell
dotnet test
```

---

### 3. JavaScript / TypeScript

Шаг 1. Поиск неиспользуемых файлов, экспортов и npm-пакетов:
```powershell
npx knip
```

Шаг 2. Автоматическое удаление неиспользуемых импортов через ESLint:
```powershell
npx eslint . --fix --rule "no-unused-vars: error"
```

Шаг 3. Ручная проверка:
- Удалить неиспользуемые внутренние функции и переменные.
- Удалить лишние пакеты из `package.json` через `npm uninstall <имя-пакета>`.

Шаг 4. Валидация:
```powershell
npm test
```

---

### 4. Python

Шаг 1. Быстрый аудит и автоисправление неиспользуемых импортов и переменных:
```powershell
ruff check --select F401,F841 --fix .
```

Шаг 2. Поиск глубокого неиспользуемого кода (функции, классы):
```powershell
vulture . --min-confidence 80
```

Шаг 3. Удаление мертвого кода и запуск тестов:
```powershell
pytest
```

## Контрольный список завершения

- Все тесты проекта успешно проходят без ошибок.
- В проекте нет незафиксированных временных файлов анализаторов.
- В модифицированном коде отсутствуют закомментированные фрагменты старого кода.
- Команда `git diff` показывает только чистое удаление ненужного кода.
