# chrome-extension-mv3

Регламент разработки браузерных расширений на Chrome Manifest V3: архитектура, безопасность и межпроцессное взаимодействие.

**Инструмент:** Google Antigravity
**Триггер:** создание, модификация или отладка браузерных расширений

## Что делает

- Фиксирует требования платформы: Service Worker вместо фоновых страниц, запрет `eval()` и внешних скриптов с CDN, состояние в `chrome.storage`, интервалы через `chrome.alarms`
- Даёт базовую структуру `manifest.json` с минимальными разрешениями
- Показывает паттерны Service Worker: инициализация периодических задач и слушателей
- Разбирает обмен сообщениями между Content Script и Background, включая обязательный `return true` в асинхронных обработчиках
- Описывает внедрение в Main World через `"world": "MAIN"` для доступа к глобальным объектам страницы
- Организует сборку через Vite и `@crxjs/vite-plugin` с HMR
- Завершается чек-листом перед публикацией: манифест версии 3, минимальные разрешения, отсутствие `eval`, проверка `chrome.runtime.lastError`

## Установка

Скопируйте каталог `chrome-extension-mv3` в папку глобальных конфигураций Antigravity:

```powershell
Copy-Item -Recurse chrome-extension-mv3 "$env:USERPROFILE\.gemini\config\skills\"
```
