# clean-documentation-readme

Регламент оформления эталонного `README.md` для программных проектов: структура, полнота, рабочие команды.

**Инструмент:** Google Antigravity
**Триггер:** оформление или обновление документации репозитория

## Что делает

- Задаёт стандартную структуру README:
  1. Заголовок и назначение проекта
  2. Ключевые возможности
  3. Системные требования с версиями
  4. Быстрый старт с минимальными командами
  5. Конфигурация и переменные окружения таблицей
  6. Сборка, тестирование и линтинг
  7. Архитектура и структура каталогов
  8. Лицензия
- Требует самодостаточности: новый разработчик разворачивает проект без устных пояснений
- Обязательное условие: все команды скопированы из актуального пайплайна и проверены
- Запрещает неактуальные ссылки, заготовки и заглушки
- Держит строгий нейтральный стиль без эмодзи
- Завершается чек-листом качества README

## Установка

```powershell
Copy-Item -Recurse clean-documentation-readme "$env:USERPROFILE\.gemini\config\skills\"
```
