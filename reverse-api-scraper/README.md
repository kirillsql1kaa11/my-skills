# reverse-api-scraper

Реверс-инжиниринг недокументированных и приватных веб/мобильных API: анализ трафика, воспроизведение авторизации, расчёт подписей, потоковая выгрузка.

**Инструмент:** Google Antigravity
**Триггер:** создание парсеров, загрузчиков и интеграций со сторонними сервисами без публичного API

## Что делает

- Этап 1 — анализ трафика: экспорт запроса из DevTools в cURL, изоляция минимального набора заголовков, поиск `timestamp`, `sign`, `token`
- Этап 2 — расчёт подписей: поиск функций хеширования в клиентском бандле (`createHmac`, `md5`, `sha256`), извлечение соли, воспроизведение алгоритма; пример HMAC-подписи на Node.js
- Этап 3 — эмуляция сессий: сохранение cookies между запросами, актуальные User-Agent, поддержка сжатия; пример запроса с retry и обработкой HTTP 429
- Этап 4 — потоковая выгрузка медиа: стримы вместо загрузки в память, проверка целостности по `Content-Length`, докачка через `Range`
- Чек-лист безопасности: секреты только через переменные окружения, задержки между запросами, обработка 401/403/429

## Установка

```powershell
Copy-Item -Recurse reverse-api-scraper "$env:USERPROFILE\.gemini\config\skills\"
```
